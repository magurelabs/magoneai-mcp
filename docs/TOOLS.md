# Tool reference

Generated by `scripts/gen_tool_reference.py` from the decorators themselves. Do not edit: `--check` regenerates and diffs on every pull request, so an edit here is reverted by CI rather than kept.

**272 tools across 26 connectors.** 159 are read-only and 54 are marked destructive.

`MCP_READ_ONLY=1` offers only the read-only ones and refuses the rest on call. `destructive` means the tool overwrites or removes rather than only adding; the specification makes that the default for any tool that is not read-only, so a `no` in that column is a claim somebody made and not merely an absence.
